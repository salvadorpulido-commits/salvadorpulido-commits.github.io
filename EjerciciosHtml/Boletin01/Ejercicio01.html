Ejercicio 1: Elementos para dar formato y Listas

Bienvenidos a la guía rápida de inicio para el ciclo de Desarrollo de Aplicaciones Multiplataforma. Es de máxima importancia asimilar los conceptos fundamentales con especial énfasis desde el primer día de clase. A lo largo del módulo trabajaremos con diversos IDEs para el aprendizaje de los diferentes lenguajes, entre ellos Java: System.out.println("Hola"), HTML: <h1>Pagina De Prueba</h1> o SQL: SELECT * FROM usuarios;, así como el uso de GitHub para registrar nuestros avances con comandos como git commit -m "mensaje". Asimismo, analizaremos los pilares básicos de la web estudiando la relación entre HTML, CSS y el DOM.
Nota: La entrega de los ejercicios dentro de plazo es obligatoria.

Lista de algunos lenguajes que se imparten

  • Java
  • HTML
  • SQL
  • CSS

Pasos secuenciales para hacer commit y push en Git

  1. Ejecutar git status para revisar los ficheros y su estado.
  2. Usar git add para incluir todos los archivos modificados
  3. Guardar la captura del proyecto en el historial local mediante git commit -m
  4. Subir los cambios al repositorio remoto ejecutando git push origin main

Definicion de algunos terminos

HTML
Lenguaje de marcas utilizado para definir la estructura y el contenido de una página web.
CSS
Lenguaje de hojas de estilo (stylesheets) empleado para controlar el diseño, la presentación y el aspecto visual de los documentos web.
DOM
Document Object Model; interfaz de programación que representa la estructura de un documento HTML como un árbol de nodos, permitiendo modificar su contenido, estructura y estilos mediante código (como JavaScript).
